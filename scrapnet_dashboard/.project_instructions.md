### 7. Aethexer Protocol Handshake (v1) — Trinity Sentinel Hardened
Formalized protocol layer for EXITZ field app ↔ Bedrock server communication.

- **Auth Guard — Trinity 3-Layer** (`lib/aethexer-auth.ts`):
  1. **Dual-key timing-safe**: `x-aethexer-key` validated against `AETHEXER_PROTOCOL_KEY` OR `AETHEXER_FIELD_KEY` via `crypto.timingSafeEqual()`
  2. **Timestamp window**: `x-aethexer-ts` header must be ±300s of server time
  3. **Nonce dedup**: `x-aethexer-nonce` header stored in `IngestNonce` model (Prisma); replays rejected. Auto-cleanup of nonces >24h old.
  - **Function is async** — all callers must `await validateAethexerKey(request)`.
- **Sentinel Engine** (`lib/sentinel-engine.ts`): 95/75/75 threshold scoring:
  - Document Integrity ≥95% (SHA-256 + magic byte validation)
  - LLM Parser Confidence ≥75% (AI extraction quality — placeholder at ingest, real after parse)
  - Spatial Correlation ≥75% (geolocation + metadata coherence)
  - Verdicts: AUTO_APPROVED / PENDING_FOUNDER / REJECTED. Score hash for audit trail.
  - Magic byte validation: PDF (`%PDF`), JPEG (`FF D8 FF`), PNG (`.PNG`), XLSX/DOCX (`PK` ZIP), PLY (`ply\n`), Splat (≥32B).
- **Protocol Envelope** (`lib/aethexer-protocol.ts`): Standard response wrapper for all `/api/v1/*` routes. Every response includes `protocol`, `backtrace`, `timestamp`, `sentinel` fields.
- **Unified Forensic Ingest** (`/api/v1/forensic-ingest`):
  - Multipart POST: `spatialScan`, `documents[]`, `groundPhotos[]`, `track`, `walletAddress`, `assetMetadata`.
  - **Magic byte validation** on every file buffer — hard reject on mismatch (HTTP 422 `MAGIC_BYTE_MISMATCH`).
  - **Sentinel scoring** runs post-validation, results stored in `parserResultJson` and returned in `sentinel` response block.
  - Creates Submission + SubmissionDocument records, returns presigned upload URLs.
- **Solana Notary Backtrace**: `anchorToDevnet()` memo payload now carries `bt` field linking to originating ingest backtrace.
- **Founder Approval Gate** (`/api/v1/submissions/[id]/approve`): PATCH endpoint protected by JWT. Sets `founderApproved`, `founderApprovedAt`, `founderApprovalNote` on Submission.
- **Settlement → Solana Bridge**: Settle route checks `founderApproved`, executes 70/20/10 split, anchors to Devnet with backtrace.
- **Schema additions**: `Submission` gained `founderApproved`, `founderApprovedAt`, `founderApprovalNote`, `ingestProtocol`, `ingestTimestamp`. `Settlement` gained `solanaSignature`, `solanaAnchoredAt`, `anchorPending`. **New model**: `IngestNonce` (nonce, usedAt) for replay protection.
- **State flow**: `DRAFT → PENDING_FORENSIC_VERIFICATION → FORENSIC_VERIFIED → [founderApproved] → SETTLEMENT_COMPLETE`
